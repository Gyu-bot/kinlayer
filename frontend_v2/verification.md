# 목업 검증 기록

아래 원본 기록은 보존하며, 저장소 인수 후 실제 브라우저 검증 결과를 마지막 절에 추가했다.

검증일: 2026-10-01

## 완료한 검사

- jsdom으로 네 화면의 DOM을 실제 실행하고 상호작용 24개를 통과했다.
- 이름/별칭 검색, 빈 결과, 관계 필터, 카드 보기, 필수 입력 오류를 확인했다.
- 인물 추가, 프로필 변경, AI 정책 변경, 기억 정정, 변경 전 출처 보존을 확인했다.
- 그래프의 중심 변경, 관계 필터, 노드/선 선택, 확대·초기화를 확인했다.
- 9번째 사람 추가 후 노드 좌표가 겹치지 않음을 검사했다.
- 같은 인물의 동료·친구 관계가 모두 유지되고, 목록 필터와 그래프에 일관되게 반영됨을 검사했다.
- 리뷰 반영·수정 후 반영·추가 확인·거절과 처리 완료 목록을 확인했다. 수정 후 반영에는 별도 정정 출처를 연결한다.
- localStorage로 화면 재진입 시 변경을 복원함을 확인했다.
- 입력값의 HTML 이스케이프, 로컬 링크 대상, HTML ID 중복, 실행 오류를 검사했다.
- 모든 HTML을 parse5로, CSS를 PostCSS로 파싱했다. 문법 오류가 없다.
- 서체 크기는 11/12/14/16/20/24/32px의 일곱 단계로 정리했다.
- 주요 텍스트 대비를 OKLch의 선형 sRGB 변환으로 계산했다. 기본 본문 18.27:1, 보조 본문 4.91:1, 주요 버튼 5.14:1, 버튼 호버 7.47:1, 성공 상태 7.26:1, 주의 상태 6.64:1이다.

## 렌더링 제한

허용된 Open Design 이미지 내보내기를 실행했으나 작업공간 컨텍스트가 필요하다는 오류로 실패했다. 작업공간 인수를 추가한 재시도에서는 작업공간 ID와 멤버 ID가 함께 필요하다는 오류가 반환됐다. 따라서 생성된 스크린샷은 없으며, 실제 픽셀 배치와 모바일 레이아웃의 시각 검증은 완료했다고 주장하지 않는다. 별도 브라우저나 헤드리스 브라우저는 실행하지 않았다.

## 연결 범위

운영 서버, 실제 인물 데이터, API, DB 및 연결 저장소를 수정하지 않았다. 화면의 데이터와 변경은 가상 데모이며, 운영 코드 통합과 배포는 포함하지 않는다.

## 저장소 인수 후 추가 검증 — 2026-10-01

- 원본 16개 파일을 비교 후 별도 작업 브랜치 `frontend_v2`로 가져왔다. 최초 복사 커밋 `46f8ed2`, 원본 체크섬은 `import-manifest.json`.
- Codex 인앱 Chromium에서 네 화면을 실제 실행했다. 1440×1000, 390×844의 네 화면 모두 캡처/시각 검사. 320×900, 768×900에서 네 화면의 가로 넘침을 추가 검사하고 주요 화면을 캡처했다. 편집창은 320×740에서도 확인했다.
- 모바일 사람 행 무반응, 필터/검색 후 다른 사람 미리보기, 잘못된 인물 링크의 다른 사람 표시, 좁은 그래프의 출처 숨김, 그래프 라벨/선택/필터 잘림, 모달 동작을 수정 후 다시 확인했다.
- 검색/필터/카드, 인물 추가/필수 입력/긴 한글/초기화, 프로필 편집과 포커스, 그래프 중심/빈 필터/확대/초기화/드래그/출처, 리뷰 수정 반영→프로필→출처를 실제 브라우저에서 확인했다. 검사 후 데모 데이터를 초기 상태로 복원했다.
- 새 재현 가능 DOM/이벤트/localStorage 검사 `interaction-checks.cjs`: **28/28 통과**. 기존 24개 검사의 소스는 전달되지 않았으며 이 수치는 별도 신규 검사 결과다.
- `node --check`로 두 실행 JS 구문 검사, PostCSS로 CSS 파싱, `git diff --check` 통과. 브라우저에서 수집된 error 로그 0개.
- 캡처는 `evidence/`, 측정은 `evidence/viewport-checks.json`, 제품·스키마 평가와 최종 화면은 [AUDIT.md](AUDIT.md).

재실행: `node frontend_v2/interaction-checks.cjs [기존 frontend/node_modules 절대경로]`. 경로를 생략하면 이 저장소의 `frontend/node_modules`를 사용한다.

현재 프론트엔드/API/DB는 변경하지 않았다. 시각/데모 상호작용 검증 완료를 실제 서비스 전체 교체 완료로 해석하면 안 된다. 실제 모바일 기기·VoiceOver 전체 동선·API 오류와 동시 수정·대규모 노드 배치는 다음 구현 단계의 검증 범위다.
