# 목업 검증 기록

검증일: 2026-10-01

## 완료한 검사

- jsdom으로 네 화면의 DOM을 실제 실행하고 상호작용 24개를 통과했다.
- 이름/별칭 검색, 빈 결과, 관계 필터, 카드 보기, 필수 입력 오류를 확인했다.
- 인물 추가, 프로필 변경, AI 정책 변경, 기억 정정, 변경 전 출처 보존을 확인했다.
- 그래프의 중심 변경, 관계 필터, 노드/선 선택, 확대·초기화를 확인했다.
- 9번째 사람 추가 후 노드 좌표가 겹치지 않음을 검사했다.
- 같은 인물의 동료·친구 관계가 모두 유지되고, 목록 필터와 그래프에 일관되게 반영됨을 검사했다.
- 리뷰 반영·수정 후 반영·추가 확인·거절과 처리 완료 목록을 확인했다. 수정 후 반영에는 별도 정정 출처를 연결한다.
- localStorage로 화면 재진입 시 변경을 복원함을 확인했다.
- 입력값의 HTML 이스케이프, 로컬 링크 대상, HTML ID 중복, 실행 오류를 검사했다.
- 모든 HTML을 parse5로, CSS를 PostCSS로 파싱했다. 문법 오류가 없다.
- 서체 크기는 11/12/14/16/20/24/32px의 일곱 단계로 정리했다.
- 주요 텍스트 대비를 OKLch의 선형 sRGB 변환으로 계산했다. 기본 본문 18.27:1, 보조 본문 4.91:1, 주요 버튼 5.14:1, 버튼 호버 7.47:1, 성공 상태 7.26:1, 주의 상태 6.64:1이다.

## 렌더링 제한

허용된 Open Design 이미지 내보내기를 실행했으나 작업공간 컨텍스트가 필요하다는 오류로 실패했다. 작업공간 인수를 추가한 재시도에서는 작업공간 ID와 멤버 ID가 함께 필요하다는 오류가 반환됐다. 따라서 생성된 스크린샷은 없으며, 실제 픽셀 배치와 모바일 레이아웃의 시각 검증은 완료했다고 주장하지 않는다. 별도 브라우저나 헤드리스 브라우저는 실행하지 않았다.

## 연결 범위

운영 서버, 실제 인물 데이터, API, DB 및 연결 저장소를 수정하지 않았다. 화면의 데이터와 변경은 가상 데모이며, 운영 코드 통합과 배포는 포함하지 않는다.
